# adiamor-storefront-v4

Adiamor storefront (diamonds, engagement rings and jewelry), migrated from Vue 2 / Nuxt 2 to Nuxt 4.

## Run

Requires Node.js 22 and a `.env` file in the project root.

```bash
# install dependencies
npm install

# start the dev server at http://localhost:3000
npm run dev

# production build
npm run build

# pre-render the static site
npm run generate

# preview the production build locally
npm run preview
```
